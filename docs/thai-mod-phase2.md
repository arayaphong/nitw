## ผล

- ไฟล์งานแปลครอบคลุม **ทั้งเกม**: 127 ไฟล์ (หนึ่งไฟล์ต่อ Yarn ที่มีบทพูด), 24,993 บรรทัด
- ไปป์ไลน์ build ข้อมูลไทยจากไฟล์งานแปลทุกไฟล์ในคำสั่งเดียว พร้อมรายงานข้อผิดพลาดและบรรทัดยาวเกิน
- รายงานความครอบคลุมจากการเล่นจริง: บรรทัดที่เกมดึงแล้วแต่ยังไม่แปล เรียงตามลำดับที่เจอ

## ข้อเท็จจริงที่ตรวจพบ

- ทุกบรรทัดที่ผู้เล่นเห็นมี `#line:` ID: บทพูด 23,904, ตัวเลือก `->` 802, ตัวเลือก `[[...|...]]` 262, บรรยาย 25; `[[...]]` ที่ไม่มี ID ทั้ง 805 รายการเป็นการกระโดดไปโหนด (ไม่มีข้อความ)
- ไม่มีตัวแปรแทรกในข้อความจริง: ที่พบ `$` คือเงื่อนไข `<<if ...>>` ของตัวเลือก (ไม่ใช่ข้อความ) และ 4 บรรทัดแปลกใน HamPanther จึง shape ล่วงหน้าได้ทั้งเกม
- line ID ซ้ำข้ามไฟล์ 3 ตัว (ข้อความต่างกัน): `11fa2f`, `314376`, `b0b9ed`
- act จากชื่อโหนด (`A#D#`): A0 26, A1 1,480, A2 4,002, A3 5,653, A4 2,541 บรรทัด, The Longest Night 2,151; ไม่มีแท็ก 9,576 (บทของสถานที่/ชาวเมืองที่ใช้ร่วมหลายวัน)

## เครื่องมือ

| ไฟล์ | หน้าที่ |
|---|---|
| `Tools/extract_thai_worklist.py` | สร้าง/อัปเดต `ThaiMod/translations/<yarn>.json` จาก Yarn ต้นฉบับใน `ThaiMod/source/yarn/` (id, โหนด, act, ชนิด, ผู้พูด, `en`, `th`, `note`); รันซ้ำไม่ทับคำแปล; เขียน `INDEX.md` สรุปตาม act/ไฟล์ |
| `Tools/prepare_thai_mod.py` | อ่านไฟล์งานแปลทุกไฟล์ (บรรทัดที่มี `th`) → `ThaiMod/data/`; รายงาน `ThaiMod/reports/thai_build.json` |
| `Tools/thai_coverage.py` | รวม key จาก `trace.log` ข้ามหลายรอบ (`reports/seen_keys.json`) → `reports/coverage.md` |

กติกาตัดบรรทัด (แก้ได้โดยไม่ต้องแก้โค้ด):
- `translations/keep_together.json` — คำที่ห้ามตัดกลาง (ชื่อเฉพาะ, คำพูดที่ ICU ไม่รู้จัก)
- `translations/no_break_after.json` — คำที่ห้ามตัดบรรทัดหลังคำนั้น (เช่น `ไม่`, `สัก`) เว้นแต่ตามด้วยช่องว่าง

การตรวจตอน build (บรรทัดที่ไม่ผ่านจะถูกข้าม เกมจึงแสดงต้นฉบับแทน และบันทึกในรายงาน):
- emoticon/markup (`:)`, `-_-`, `{width=4}` ฯลฯ) ในคำแปลต้องตรงกับต้นฉบับ
- ตัวอักษรละตินในคำแปลต้องมีในฟอนต์ sprite ของเกม และกลุ่มอักษรไทยต้องมีในฟอนต์ไทย
- บรรทัดที่เกิน 3 แถวแม้ขยายเป็น 4.5 จะถูกรายงานพร้อมจำนวนแถวของต้นฉบับอังกฤษ

## การเปลี่ยนแปลงใน runtime

- ID ซ้ำข้ามไฟล์: `strings.tsv` มีคอลัมน์ที่ 4 เป็นข้อความต้นฉบับสำหรับ ID ที่ซ้ำ; hook `GetString` รับ `this` (Program) แล้วอ่าน `Program.strings[key]` เพื่อเลือกคำแปลที่ต้นฉบับตรงกัน
- hook ยังเป็นชุดเดิมที่ปลอดภัย (`GetString`, `GetCharData`, `SetText`); การเพิ่ม `this` ให้ `GetString` ทดสอบในเกมแล้ว ปุ่มยืนยันที่ Title ยังใช้ได้

## ข้อสังเกตจากการเล่นทดสอบ

- กล่องข้อความทีวี (สี่เหลี่ยมมุมขวาบน) เป็น `SpriteText` เช่นกัน ภาษาไทยแสดงได้โดยไม่ต้องแก้เพิ่ม
- ตัดคำผิดที่ที่เจอ ("ไม่|สะเทือน", "ให้ไม่|อั้น", "สัก|คน") แก้ด้วย `no_break_after.json`
