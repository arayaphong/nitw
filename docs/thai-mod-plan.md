# แผนทำ Thai mod สำหรับ Night in the Woods

ปรับปรุง 6 พฤศจิกายน 2026 · branch `thai-mod`

## เป้าหมาย

- **เป้าหมายสุดท้าย:** เล่น Night in the Woods บน Android เป็นภาษาไทย
- **เป้าหมายระหว่างทาง (ใช้งานได้ด้วยตัวเอง):** เล่นเกมเวอร์ชัน Steam บน Linux แบบเดิม แต่มีภาษาไทย

## การตัดสินใจ

งานสร้างเกมขึ้นใหม่ทีละฉาก (`NITW-Unity-Reconstruction`) **พักไว้ก่อน** การถอด CIL มาเขียนพฤติกรรมใหม่ทุกฉากไม่คุ้มเมื่อเทียบกับขนาดเกม (195 ฉาก, คำสั่ง Yarn 257 ชื่อ, Brain เฉพาะฉาก 34 ชนิด)

แนวทางใหม่คือ **mod บนเกมเดิม**: ใช้ `Assembly-CSharp.dll`, ฉาก, เสียง และระบบเซฟของเกมจริงทั้งหมด แล้วเพิ่มเฉพาะภาษาไทยและตัววาดตัวอักษรไทยด้วย BepInEx 5 + Harmony ไม่แก้ไฟล์เกมต้นฉบับ

งาน Android จะทำทีหลังด้วยการ re-host: นำ DLL และ assets เดิมไปลง Unity project (เช่น export ด้วย AssetRipper) แล้วเปลี่ยนเฉพาะชั้นแพลตฟอร์ม (FMOD Android, Steam stub, Rewired/ระบบสัมผัส) ข้อมูลภาษาไทยจาก mod จะใช้ต่อได้ทั้งหมด

## สิ่งที่ตรวจพบแล้ว

- เกมเป็น Unity `5.6.2p4` แบบ Mono; managed assemblies เป็น IL แบบ AnyCPU
- เกม **มีระบบแปลภาษาในตัว**: คลาส `Localization` (fields `useLanguage`, `stringGroups`, `languageDatas`; methods `SetUseLanguage`, `InitDialogueRunner`, `GetLanguageData`) และ `Yarn.Unity.LocalisedStringGroup` (`language`, `stringFiles`)
- ตารางคำแปลเป็น CSV `LineCode,LineText,Comment` ผูกกับ line ID ของ Yarn (`line:xxxxxx`); ในเกมมีตารางภาษาอิตาลีที่ทำไม่ครบอยู่ 28 ไฟล์
- ตัววาดข้อความคือ `SpriteText` + `SpriteFont` (glyph เป็น sprite รายตัวอักษร, รองรับ `upperCaseOnly`, `lineHeight`, การตัดบรรทัดตามความกว้าง) จึงวาดภาษาไทยที่ต้อง shape ไม่ได้โดยตรง
- บทสนทนา Yarn: 138 ไฟล์, ราว 25,000 บรรทัดที่มี line ID, ราว 150,000 คำ; บรรทัดที่มีตัวแปรแทรกมีราว 10 บรรทัด จึง shape ภาษาไทยล่วงหน้า (offline) ได้เกือบทั้งหมด
- ระบบภาษาไทยที่พิสูจน์แล้วในงาน reconstruction: HarfBuzz shaping, ฟอนต์ Kanit Medium, การตัดบรรทัดด้วย ICU พร้อมรายการคำห้ามตัด, atlas แบบ mipmap และ mip bias −0.5 สำหรับ 960×540

## หลักการ

- ไม่แก้ไฟล์เกมใน Steam; mod ต้องถอดออกได้และเกมกลับเป็นอังกฤษตามเดิม
- สำรองเซฟก่อนทดสอบทุกครั้ง; ทดสอบด้วยโปรไฟล์/เซฟแยกเมื่อทำได้
- คำแปลบทเกม ข้อมูล glyph ที่มีข้อความ และ assets ของเกมเก็บในเครื่องเท่านั้น ไม่ขึ้น repository นี้ (ดู `PUBLICATION.md`)
- ทุกเฟสจบด้วยการทดสอบในเกมจริงและ commit; push เมื่อผู้ใช้อนุมัติ

## เฟสงาน

### เฟส 0: ฐาน mod (ยังไม่มีคำแปล)

- ติดตั้ง BepInEx 5 บนเกม Steam Linux และตั้ง launch option ของ Steam
- plugin ตัวแรกบันทึก line ID ทุกบรรทัดที่เกมแสดง พร้อมชื่อไฟล์ Yarn และโหนด
- อ่าน CIL ของ `Localization`, `LocalisedStringGroup`, `SpriteText.SetText/ParseText/SpawnLetter` และจุดที่ `DialogueRunner` รับ string table เพื่อหาจุดเสียบที่น้อยที่สุด
- **เสร็จเมื่อ:** เกมเปิดผ่าน Steam พร้อม mod ได้, เล่นและเซฟได้ปกติ, มี log line ID, และถอด mod ออกแล้วเกมกลับเป็นเหมือนเดิม

### เฟส 1: ภาษาไทยในเกมจริง (vertical slice)

- เพิ่มภาษา `th` เข้า `Localization` ของเกม โดยใช้ตาราง CSV ตามรูปแบบเดิม
- ย้ายตัววาดบับเบิลไทยเข้า `SpriteText`: หนึ่งกลุ่มอักษรไทยเป็นหนึ่ง letter เพื่อให้จังหวะพิมพ์, เสียง, การเด้ง และการ fade เป็นของเกมเดิม
- ใช้คำแปลที่มีแล้ว: IntroPoem 36 บรรทัด + BusStation 31 บรรทัด
- **เสร็จเมื่อ:** เมนู → บทกวี → BusStation → คุยกับ Janitor เป็นภาษาไทยในเกมจริง, สลับไทย/อังกฤษได้, ภาพทุกบรรทัดผ่านการตรวจเลเอาท์

### เฟส 2: ระบบสำหรับงานแปล

- ดึงบทออกเป็นไฟล์งานแปลแยกตามไฟล์ Yarn และตามบทของเกม: id, ผู้พูด, ต้นฉบับ, คำแปล, โหนด, หมายเหตุ
- คำสั่งเดียว build ข้อมูลไทยทั้งหมด (CSV + ข้อมูล shape + atlas) และตรวจว่า emoticon/markup ในบรรทัดยังครบ
- ในเกม: รายงานบรรทัดที่แสดงแล้วแต่ยังไม่มีคำแปล และเตือนบรรทัดที่เกิน 3 แถว
- รองรับบรรทัดที่มีตัวแปรแทรก (fallback แบบ shape ตอนรันหรือแบบกฎปรับตำแหน่งสระ/วรรณยุกต์)
- **เสร็จเมื่อ:** แปลเพิ่ม → build → ทดสอบในเกม ได้ในรอบเดียว

### เฟส 3: แปลตามบทของเกม

แต่ละบททำเป็นรอบ: แปล → build → เล่นทดสอบบทนั้น → แก้เลเอาท์/คำห้ามตัด → commit

- ตรวจทานภาษาทั้งเกม, ปรับฟอนต์ (เช่น การสั่นแบบลายมือ 3 เฟรมแบบฟอนต์เดิม), สคริปต์ติดตั้ง/ถอนการติดตั้ง

### หลังจากนั้น: Android

ใช้ข้อมูลภาษาไทยชุดเดียวกันกับงาน re-host บน Android; ข้อจำกัดที่ต้องตรวจ: Unity 5.6 ออก Android ได้เฉพาะ ARMv7 32-bit, เครื่องที่ไม่รองรับ 32-bit ต้องอัป Unity และใช้ IL2CPP ARM64

## ความเสี่ยงและคำถามค้าง

- ยังไม่ได้ทดสอบ BepInEx 5 กับเกมนี้บน Linux (Unity 5.6, Mono) — เฟส 0 ต้องพิสูจน์
- ยังไม่รู้ว่าระบบ `Localization` เปิดเลือกภาษาผ่าน UI ได้หรือถูกปิดไว้ (`enableLanguageSwitch`, `overrideLanguage`)
- ข้อความบางส่วนอาจไม่ผ่าน Yarn/`SpriteText` (เช่น UI, TextMesh) ต้องหาจุดเสียบแยก
- งานแปล ~150,000 คำเป็นงานใหญ่: ร่างแปลทีละบทแล้วให้ผู้ใช้ตรวจสำนวน
